SOLUTION LA PLUS SIMPLE - CSS UNIQUEMENT :
========================================

Si le JavaScript ne fonctionne pas, utilisez cette solution CSS pure.
Cela masquera TOUJOURS les modes d'expédition sur la page checkout.

========================================

Shopify → Thèmes → Personnaliser → Paramètres du thème → CSS additionnel

Collez ce code :

/* Masquer TOUTES les sections d'expédition sur checkout */
body[data-checkout="true"] fieldset#shipping_methods,
body[data-checkout="true"] input[name="shipping_methods"],
body[data-checkout="true"] .yyi4nyn.yyi4nyk.yyi4nyr.yyi4nys,
body[data-checkout="true"] h3[id="shippingMethod"],
body[data-checkout="true"] section[aria-labelledby*="shipping"],
body[data-checkout="true"] [id*="shipping_methods"] {
    display: none !important;
    visibility: hidden !important;
    height: 0 !important;
    overflow: hidden !important;
}

/* Alternative : masquer si on est sur checkout (plus simple) */
@media all {
    body:has(input[name="shipping_methods"]) section:has(input[name="shipping_methods"]),
    body:has(input[name="shipping_methods"]) fieldset:has(input[name="shipping_methods"]),
    body:has(.yyi4nyn) section:has(.yyi4nyn),
    h3[id="shippingMethod"] {
        display: none !important;
    }
}

/* Masquer directement les éléments avec les classes spécifiques */
.yyi4nyn.yyi4nyk.yyi4nyr.yyi4nys,
input[name="shipping_methods"] {
    display: none !important;
    visibility: hidden !important;
}

input[name="shipping_methods"] ~ *,
.yyi4nyn ~ * {
    display: none !important;
}

========================================
ATTENTION : Cette solution masquera TOUJOURS les modes d'expédition sur le checkout,
même pour les produits normaux. Utilisez seulement si vous vendez UNIQUEMENT des dons,
ou si vous voulez tester rapidement.

========================================
