# Images Directory

Placez vos images ici :

## Icônes PWA requises
- `icon-192.png` - 192x192 pixels (requis)
- `icon-512.png` - 512x512 pixels (recommandé)

## Logo
- `logo.png` - Logo principal du site

## Images de contenu
- `hero-1.jpg` - Image principale de la section hero
- `hero-2.jpg` - Image secondaire hero
- `hero-3.jpg` - Image secondaire hero
- `news-1.jpg` à `news-6.jpg` - Images pour les cartes d'actualités

## Notes
- Utilisez des images optimisées pour le web (format WebP recommandé)
- Compressez les images pour améliorer les performances
- Respectez les dimensions recommandées pour chaque image

## Outils recommandés
- [TinyPNG](https://tinypng.com/) - Compression d'images
- [Squoosh](https://squoosh.app/) - Optimisation d'images
- [Favicon Generator](https://realfavicongenerator.net/) - Génération d'icônes PWA
